# Classical Machine Learning Examples (Python)

This repository contains a collection of simple examples of **classical Machine Learning algorithms implemented in Python**.

The goal of this project is to demonstrate practical understanding of common ML workflows, including data preprocessing, model training, and evaluation.

## Topics Covered

Examples in this repository include:

- Data preprocessing and feature scaling
- Exploratory data analysis
- Supervised learning models (e.g., regression and classification)
- Model evaluation and validation
- Basic ML pipelines

## Tech Stack

The examples mainly use the following Python libraries:

- numpy
- pandas
- scikit-learn
- matplotlib

## Purpose

This repository is part of a personal learning portfolio and serves as a collection of small, clear implementations of fundamental Machine Learning techniques.

The focus is on **clarity and educational value**, rather than production-ready systems.

## Usage

Each script or notebook can be run independently and demonstrates a specific Machine Learning concept or algorithm.
